## Project Overview

This project focuses on analyzing coffee shop sales data from January to June 2023 using Microsoft Excel.

The goal of this analysis was to understand sales performance, identify best-selling products, evaluate store performance, and discover sales trends to support better business decisions.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Excel Dashboard
- Data Cleaning and Analysis

## Dataset Description

The dataset contains 149,116 transaction records with 12 columns, including:

- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail
- Total Sales

## Business Questions

The analysis aimed to answer the following questions:

1. What is the total sales revenue generated?
2. Which product categories generate the highest revenue?
3. Which products are the best sellers?
4. Which store location generates the highest sales?
5. Which months record the highest and lowest sales?
6. How does product demand vary across different categories?

## Key Performance Indicators (KPIs)

| KPI                 | Result         |
| ------------------- | -------------- |
| Total Sales Revenue | $698,812.33     |
| Total Transactions  | 149,116        |
| Total Quantity Sold | 214,470        |
| Reporting Period    | Jan – Jun 2023 |

## Key Insights

### 1. Product Category Performance

- Coffee was the highest revenue-generating category, with $269,952.45 in sales.
- Tea followed with $196,405.95.
- Bakery generated $82,315.64.
- Packaged Chocolate recorded the lowest category revenue, with 4,407.64.

### 2. Best-Selling Products

- Barista Espresso was the highest revenue-generating product type, with $91,406.20 in sales.
- Brewed Chai Tea generated $77,081.95.
- Hot Chocolate generated $72,416.00.

### 3. Monthly Sales Performance

- June recorded the highest sales, generating $166,485.88.
- May followed with $156,727.76.
- February recorded the lowest sales, generating $76,145.19.

### 4. Store Location Performance

Based on sales revenue calculated from the transaction records:

- Hell's Kitchen generated $236,511.17.
- Astoria generated $232,243.91.
- Lower Manhattan generated $230,057.25.

## Recommendations

Based on the analysis, the following recommendations can be considered:

1. **Focus on High-Performing Products:** Maintain sufficient stock of popular products such as Barista Espresso and Brewed Chai Tea.
2. **Improve Low-Performing Categories:** Develop marketing strategies and promotions to improve sales of Packaged Chocolate and other lower-performing categories.
3. **Leverage Peak Sales Periods:** Use the strong sales performance in May and June to plan inventory and promotional campaigns.
4. **Improve Store Performance:** Investigate the differences in sales across locations and identify opportunities to improve performance.
5. **Strengthen Product Marketing:** Continue promoting Coffee and Tea categories because they contribute significantly to total revenue.
